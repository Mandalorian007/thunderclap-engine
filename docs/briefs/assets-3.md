## Goal

The glTF files an artist exports from Blender with default settings load without a warning, cosmetics ship as glTF material variants, and a game holding many assets has one cache that knows what is loaded and what it costs. All parsing CPU-side in `src/assets`; nothing new in `src/render` (a GPU-side gap is a wish for ws/render-5).

STATUS row, *done when*:

- **Mesh quantization** (`KHR_mesh_quantization`): normalized and non-normalized `BYTE`/`SHORT` positions, normals, tangents and texcoords are read through the accessor path into the existing float layouts (dequantized on load, documented; a later render pass can keep them packed). Test: a quantized cube built by the harness writer loads to the same positions as its float twin within 1e-4 after the node transform.
- **Meshopt** (`EXT_meshopt_compression`, `src/assets/meshopt.ts`): a TypeScript port of the meshoptimizer decoder for the `ATTRIBUTES`, `TRIANGLES` and `INDICES` modes and the `OCTAHEDRAL`, `QUATERNION`, `EXPONENTIAL` filters, reading the fallback buffer only when the extension is absent; decode is synchronous on a `Uint8Array`, allocation per buffer view only. The encoder is test-only (`meshopt.test.ts` holds a small reference encoder or known vectors from the spec, documented which). Test: round-trips of attribute and index streams; each filter decodes known vectors; a meshopt GLB loads to the same mesh as its uncompressed twin.
- **Lights and cameras** (`KHR_lights_punctual`, `cameras`): `GltfDocument.lights` (`{ type: 'directional' | 'point' | 'spot', color, intensity, range?, innerConeAngle?, outerConeAngle? }` in the engine's units, conversion documented) and `GltfDocument.cameras` (perspective and orthographic), each with the world transform of the node that carries it; `loadGltf` returns them as plain descriptors a game hands to `render`'s light and camera calls (no render edits). Tests: a node-attached spot light comes back with its world direction and cone; a perspective camera's `yfov`/`aspect`/`znear`/`zfar` round-trip.
- **Material variants** (`KHR_materials_variants`): `GltfDocument.variants: string[]`, per-primitive mappings, and `loaded.setVariant(name | null)` that swaps the bound material on every mapped primitive in place (no re-upload: materials for every variant are created once at load). This is the cosmetic path: name it so in the README with a three-line example. Tests: switching variants changes the primitive's material id and back; an unknown name throws with the list.
- **Small debts**: `occlusionTexture.strength` carried to the standard material's occlusion factor if it has one (else a wish naming the field); `KHR_materials_*` extensions the material cannot express (`clearcoat`, `sheen`, `transmission`, `volume`, `ior`, `specular`) are parsed into `GltfMaterial.extensions` as typed records and reported once by `unsupportedExtensions` rather than warned per primitive; `extensionsRequired` still throws for anything unhandled.
- **KTX2 container** (`src/assets/ktx2.ts`): `parseKtx2(bytes)` → `{ vkFormat, width, height, depth, layers, faces, levels: { bytes, width, height }[], dataFormat, supercompression }` (header, level index, DFD basic block; Zstandard and BasisLZ supercompression detected and reported, not decoded); `ktx2ToWebGpuFormat(vkFormat)` mapping for the uncompressed, BC, ETC2 and ASTC formats; `KHR_texture_basisu` image references parsed and surfaced. No upload: the README names the render call ws/render-5 needs. Tests: an RGBA8 KTX2 built in the test parses to its pixels; a BC7 header maps to `'bc7-rgba-unorm'`; supercompressed files report `supercompression` and no levels.
- **Asset cache** (`src/assets/cache.ts`): `createAssetCache({ budgetBytes, onEvict? })` → `acquire(key, load: () => Promise<T>, size: (T) => number)` (dedupes concurrent loads of one key, refcounted), `release(key)`, `pin(key)`, `stats()` (`{ bytes, entries, hits, misses, evictions }`), LRU eviction of unreferenced, unpinned entries once over budget, `dispose(key)` hook so a game frees GPU objects; works over `bundle.ts`'s `read`. Tests: two concurrent acquires call `load` once; eviction order is LRU among refcount-0 entries; a pinned entry survives; stats count.
- **Harness**: extend through new pages only: `harness/gltf3.html` + `gltf3.ts` + `gltf3-state.ts` building GLBs with `gltf-writer.ts` helpers (add helpers there additively): `?quant` (quantized vs float cube side by side; state `maxError`), `?meshopt` (a meshopt rock; state `triangles`, `match`), `?lights` (a scene lit by its own glTF lights; state `lights`), `?variants` (a character-like mesh cycling three variants each second; state `variant`, `materialId`), `?cache` (loads ten assets into a small budget; state `stats`), `?still` parks. `e2e/gltf3.spec.ts` (E-017 polling), `e2e/gltf.spec.ts` green, `pnpm snap:check` 0 px.
- **Docs**: assets README sections *Quantized meshes*, *Meshopt*, *Lights and cameras*, *Material variants (cosmetics)*, *KTX2*, *Asset cache*; the *Not yet* list rewritten to what is still out (Draco, KTX2 upload and Basis transcoding, GPU morphs); types list; CHANGELOG block; ARCHITECTURE assets clause (one sentence); root README harness list + count line.
