# Brief: ws/geom-2

Read `docs/briefs/common.md` first, then DECISIONS E-015 (3D quality bar), E-021; `src/geom/README.md` whole, `src/geom/geometry.ts` (`GeometryWriter`, `mergeGeometry`, `transformGeometry`, `computeBounds`), `src/geom/primitives.ts` (one builder end to end), `src/render/mesh.ts` (`VertexLayout`, `VERTEX_LAYOUT_3D`, how a layout declares attributes), `harness/geom.ts`.

## Goal

The second half of a procedural geometry kit: shapes swept from 2D profiles, a tangent frame for normal-mapped materials, and the per-geometry operations a level builder reaches for (flat shading, uv projection, welding, flipping, bounds-fit). Pure arithmetic, no GPU, no new runtime deps.

STATUS row, *done when*: `extrude(profile, opts)`, `lathe(profile, opts)`, `sweep(profile, path, opts)`, `polygon(points, opts)`, `stairs(opts)`, `arch(opts)`, `tube(path, opts)` return `Geometry` in `VERTEX_LAYOUT_3D`; `VERTEX_LAYOUT_3D_TANGENT` (16 floats: position, normal, uv, rgba, tangent xyz + handedness) is exported from `render/mesh.ts` and `computeTangents(geometry)` returns a geometry in it (MikkTSpace-style per-triangle accumulation, orthonormalised, handedness in w); `flatShade(g)`, `weld(g, epsilon?)`, `flipWinding(g)`, `projectUv(g, 'box' | 'planar' | 'cylindrical' | 'spherical', opts?)`, `fitBounds(g, size)`, `recenter(g)`; harness `geom.html` gains the new shapes (a second row) and one tangent-space probe; documented.

## Scope

- `src/geom/sweep.ts`: `Profile2D = Float32Array | number[]` of x, y pairs, counter-clockwise; `extrude(profile, { depth, segments?, caps?, bevel? })` along +z with flat side normals and capped ends (ear-clip triangulation for the caps: write `triangulate(profile): Uint16Array | Uint32Array` in `src/geom/triangulate.ts`, handles concave simple polygons, throws on self-intersection detection being out of scope but documents it); `lathe(profile, { segments = 24, angle = 2π })` around +y; `sweep(profile, path: Float32Array, { closed?, frames?: 'frenet' | 'rmf' })` with rotation-minimising frames by default; `tube(path, { radius, segments, closed })` as `sweep` of a circle; `polygon(points, { y?, doubleSided? })` a flat triangulated polygon.
- `src/geom/shapes.ts`: `stairs({ steps, width, rise, run, sides? })`, `arch({ width, height, depth, thickness, segments })`: level-building shapes built from the primitives above through `GeometryWriter`/`mergeGeometry`.
- `src/geom/tangents.ts` + `render/mesh.ts`: `VERTEX_LAYOUT_3D_TANGENT` next to `VERTEX_LAYOUT_3D` (`shaderLocation` 4 for the tangent); `computeTangents(g)` allocates once; `GeometryTangent` type alias. Nothing in `renderer.ts`, `wgsl.ts`, `standard.ts`: the shader side is ws/gltf-materials.
- `src/geom/ops.ts`: `flatShade` (unshares every vertex, face normals), `weld` (position+normal+uv within `epsilon`, spatial hash, remaps indices, shrinks to 16-bit when it fits), `flipWinding` (and negates normals), `projectUv` (box: dominant normal axis; planar: given axis; cylindrical/spherical: around +y), `fitBounds` (uniform scale so the AABB's largest side equals `size`), `recenter` (translate so the AABB centre is the origin). All return the same `Geometry` mutated except `flatShade`, `weld`, `computeTangents` which return new ones (they change counts); documented per function.
- Tests: `sweep.test.ts` (vertex/triangle counts, cap normals, closed sweep seam, concave extrude cap area equals polygon area), `triangulate.test.ts` (convex, concave, collinear points), `tangents.test.ts` (tangent ⟂ normal, unit, handedness ±1, a mirrored uv flips w), `ops.test.ts` (weld removes duplicates exactly, flat shade triangles × 3 vertices, projectUv ranges, fitBounds extents, flipWinding keeps bounds).
- Harness `harness/geom.ts`: second row of shapes (extruded star, lathed vase, swept tube along a helix, stairs, arch) lit like the first; `geom-state.ts` exposes `shapes` count and a `tangentW` probe (sum of handedness signs over one mesh = vertex count); `e2e/geom.spec.ts` extends the shape count and adds the probe. Keep the first-row probes pixel-identical (add shapes to the right/below, do not move the camera).
- Docs: geom README *Sweeps*, *Tangents*, *Operations* sections and the builder table rows; render README *Vertex layouts* one line for the tangent layout; CHANGELOG one line; ARCHITECTURE *Geometry* one sentence.
