# Brief: ws/i18n

Read `docs/briefs/common.md` first, then `docs/VISION.md`; `src/save/README.md` and `src/save/schema.ts` (house style for a dependency-free module with a tiny typed DSL); `src/ui/README.md` (how text reaches the DOM: `Overlay`, `ui.toast`, menus, HUD if landed); `src/platform/environment.ts` (how the engine reads browser facts); `scripts/check-boundaries.mjs` (every new module must be registered if it lists modules); `package.json` `exports`.

## Goal

A game ships in several languages without a dependency. `@thunderclap/engine/i18n` loads a string table per locale, formats messages with placeholders, plurals, and gender/select, formats numbers, dates and durations through `Intl`, falls back along a chain, exposes the result as a function the game and the UI module call, and swaps locale at runtime with a subscription so the UI re-renders. Strings only: no asset loading beyond `fetch` of the game's own JSON when the game asks for it, no network otherwise.

STATUS row, *done when*: `createI18n(desc)` with `I18nDesc {locale, fallback?: string | string[], tables: Record<locale, Table | () => Promise<Table>>, missing?: 'key' | 'throw' | ((key, locale) => string), onMissing?}` → `I18n {locale, t(key, args?), has(key), setLocale(locale): Promise<void>, subscribe(fn): () => void, formatNumber, formatDate, formatDuration, formatList, direction: 'ltr' | 'rtl', locales}`; messages use ICU-style `{name}`, `{count, plural, one {..} other {..}}` (uses `Intl.PluralRules`, `=0` exact forms, `#`), `{g, select, male {..} female {..} other {..}}`; nested keys `menu.start`; tables parsed once into an AST per key, formatting allocates only the output string; `negotiateLocale(available, requested: readonly string[] = navigator.languages)` picks the best match (exact, then language, then fallback); `direction` from a small RTL language set; the UI module stays untouched but README shows `ui.toast(i18n.t('saved'))` and a `subscribe` re-render example; harness `i18n.html` (locale switcher, plural counter, RTL sample, state exposes `locale`, `sample`, `direction`); `pnpm check` boundaries pass; documented.

## Scope

- `src/i18n/`: `message.ts` (parser + formatter, errors name the key and column), `i18n.ts` (store, fallback chain, async table loading with a pending promise per locale, subscription), `negotiate.ts`, `index.ts`, `README.md`, tests for parser (every syntax form, malformed input), plurals across `en`/`ru`/`ar` (via `Intl.PluralRules`), fallback chain, lazy table load, `negotiateLocale`, `direction`.
- `package.json`: `"./i18n": "./src/i18n/index.ts"`; `scripts/check-boundaries.mjs` if it enumerates modules (i18n may import nothing from the engine except `platform` types if needed; nothing may import i18n except `ui` later).
