## Goal

The third post pass: the effects a modern-looking 3D game is judged by that the stack still lacks. Temporal anti-aliasing with a history buffer and jittered projection (replacing FXAA when on), screen-space reflections on the standard material's roughness, auto-exposure from a luminance histogram, a colour-temperature and tint control before the grade, per-object motion blur is out (no velocity target); camera motion blur from the depth and the previous view-projection is in; a lens-dirt texture on the bloom; and a `PostQuality` tier table that turns the expensive ones off on phones. Every one off by default and free while off; 2D pages pixel-identical.

STATUS row, *done when*:

- **TAA** (`TaaSettings`: `enabled`, `feedback` 0.9, `sharpen` 0.2, `clampMode: 'aabb' | 'variance'`): the stack owns a history colour texture at scene res (`rgba16float`), reprojects it by the previous frame's view-projection against the current depth, neighbourhood-clamps, blends by `feedback`, and the stack exposes `taa.jitter(frame) → [x, y]` (Halton 2,3 sequence over 8 or 16 samples in pixel units) that the renderer or the game adds to the camera's projection each frame: document the one-line call in the Camera (`camera.setJitter(x, y)` if `Camera` has it; if not, implement the jitter inside `src/post` by applying a sub-pixel UV offset at history resolve and report that a proper projection jitter is a `Camera` wish); when `taa.enabled` FXAA is skipped. Resize and first frame reset the history. Unit tests on the jitter sequence (zero mean, bounded), the reprojection matrix math, and the blend weight clamp.
- **SSR** (`SsrSettings`: `enabled`, `maxSteps` 32, `thickness`, `maxDistance`, `roughnessCutoff` 0.6, `intensity`, `fadeEdges`): half-res ray march in view space over the depth buffer from the normals-from-depth the AO pass already derives (share that helper), sampling the scene colour, faded by roughness and screen edge, composited before bloom. The composite needs per-pixel roughness: the standard material writes none today, so SSR reads `roughnessCutoff` as a global and reports the wish for a material-property target (do not touch `src/render`). Tests on the march step function and the edge fade.
- **Auto-exposure** (`ExposureSettings`: `mode: 'manual' | 'auto'`, `minEv`, `maxEv`, `speedUp`, `speedDown`, `keyValue` 0.18, `histogramLow` 0.4, `histogramHigh` 0.95): a compute pass builds a 64-bin log-luminance histogram of the scene colour, a second computes the average between the percentile bounds, and the exposure eases toward it by the speeds (dt from `PostInputs.dt`); `tonemap.exposure` becomes the manual value when `mode` is `'manual'`; `post.exposure` exposes the current EV for the HUD. Tests with a fake device on the bin math and the adaptation curve (CPU reference implementation of the two kernels against a tiny image).
- **White balance** (`WhiteBalanceSettings`: `temperature` 6500 K, `tint` 0): a 3×3 colour-matrix multiply before the grade (Bradford or the common approximation; cite which). Tests: 6500/0 is identity, lower temperature warms.
- **Camera motion blur** (`MotionBlurSettings`: `enabled`, `intensity`, `maxSamples` 8): per-pixel velocity from the current depth reprojected by the previous view-projection (the same matrix TAA keeps), sampled along the vector in the composite before bloom. Tests on the velocity derivation for a pure yaw.
- **Lens dirt** (`BloomSettings.dirt?: { texture, intensity }`): a texture multiplied into the bloom term at composite; `createLensDirtTexture(device, size, seed)` paints a procedural one (speckles and smudges); off when `texture` is null. Test: null texture leaves the composite shader path unchanged (uniform flag).
- **Quality tiers**: `PostQuality` gains `taa`, `ssr`, `autoExposure`, `motionBlur` caps; `lowPostQuality()` turns `ssr` and `motionBlur` off and keeps TAA; a new `postQualityFor(tier: 'phone' | 'tablet' | 'desktop' | 'xr')` helper; `PostQuality.xr` rule: TAA and SSR off (the XR path is single-pass per eye today and the history would be wrong across eyes: say so in the README).
- **Uniform block**: grow `POST_UNIFORM_FLOATS` and `WGSL_POST_UNIFORMS` coherently; `settings.test.ts` asserts the pack size equals the WGSL struct size for every field.
- **Harness** `harness/post3.html` + `post3.ts` + `post3-state.ts`: a lit scene with a rotating shiny floor, a bright sky patch and a dark corner, the camera orbiting slowly; query flags `?taa`, `?ssr`, `?autoexp`, `?wb=3200`, `?mblur`, `?dirt`, `?still`; state exposes `exposure`, `taaActive`, `ssrActive`, `historyResets`, `passes` (names in order this frame), `frameMs`. `e2e/post3.spec.ts` (one page load, polled assertions, each test under 10 s): with `?taa` a probe on a high-contrast edge has lower variance across three frames than without; `?ssr` brightens a probe on the floor under the sky patch; `?autoexp` moves `exposure` from its start within 2 s and settles (delta between two late samples below a threshold); `?wb=3200` raises the red/blue ratio at a grey probe; `?dirt` changes a bloom probe; the passes list contains the enabled passes in the documented order; all 2D pages unchanged: `pnpm snap:check` 0 px; `e2e/post2.spec.ts` and `depth-post.spec.ts` green.
- **Docs**: post README rows in the *Passes* table and a *Post 3* section (what each needs from the renderer; the TAA jitter hand-off; the roughness-target and velocity wishes), CHANGELOG block, ARCHITECTURE Post clause (one sentence), root README harness item + count line.
