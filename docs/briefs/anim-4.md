## Goal

The character motion a third-person action game needs beyond clips: a 2D blend space (strafe sets), an aim/look offset as an additive layer, foot placement against a ground probe, secondary motion (spring chains for capes, hair, tails, holstered gear) so cosmetics lag and settle, pose matching so a transition starts at the nearest frame, and clip compression so a wardrobe of animations fits. Everything is CPU pose arithmetic between sampling and `poseToWorld`, zero allocation per frame, no new ties to `render/`.

STATUS row, *done when*:

- **2D blend space** (`graph.ts`): `AnimGraphBlendState` accepts `blend: { params: [px, py], points: [{ at: [x, y], clip }], syncPhase? }` (gradient-band or barycentric over a Delaunay of the points, computed once; document which); weights sum to 1, a query outside the hull clamps to the hull. 1D stays as is. Tests: a point on a sample returns that clip at 1; the centre of three equilateral samples returns 1/3 each; outside clamps.
- **Aim offset** (`src/anim/aim.ts`): `createAimOffset(skeleton, { joints: [spine1, spine2, head], weights: [0.3, 0.3, 0.4], maxYaw, maxPitch })` + `applyAimOffset(pose, skeleton, worldPose, aim, targetWorld, instanceWorld, { weight })`: distributes the yaw/pitch toward a world target across the chain (a multi-joint `lookAt`), clamped, additive on top of the sampled pose; a `lookAt` call stays correct for a single joint. Test: the summed rotation reaches the target within the clamps; weights distribute.
- **Foot placement** (`src/anim/foot-ik.ts`): `createFootIk(skeleton, { feet: [{ root: hip, mid: knee, tip: foot, toe? }], probe: (x, z, out: [y, nx, ny, nz]) => boolean, pelvis, maxLift, maxDrop, blend })`, `applyFootIk(pose, skeleton, worldPose, footIk, instanceWorld, dt)`: probes under each foot, lowers the pelvis to the lowest contact, runs `twoBoneIk` per leg to the ground height, tilts the foot to the normal, smoothed by `blend` per second; a flat probe is a no-op (pose unchanged, test). Tests on a stepped probe (one foot on a 0.2 ledge: pelvis drops, both feet reach ground, knees bend the right way); allocation-free in the frame call (count with a test allocation probe if the repo has one, else document).
- **Secondary motion** (`src/anim/spring-chain.ts`): `createSpringChain(skeleton, { root, tip (or joints[]), stiffness, damping, gravity, drag, radius, limitAngle })`, `updateSpringChain(pose, skeleton, worldPose, chain, instanceWorld, dt)`: a Verlet chain whose rest shape is the sampled pose each frame (so authored motion still drives it), each joint's rotation rewritten to point at its simulated child, `collide: SpringCollider[]` spheres and capsules in instance space (a shoulder sphere keeps a cape off the chest); fixed sub-step (`maxDt` split, default 1/120); `reset()` snaps to rest; the whole thing is `teleport`-safe (a large instance move in one frame does not fling the chain: detect by `teleportDistance`). Tests: a chain under gravity settles below rest within N steps; a sphere collider holds a joint outside; teleport does not add velocity.
- **Pose matching** (`src/anim/match.ts`): `buildPoseFeatures(clip, skeleton, { joints, sampleRate })` (per-sample joint positions + velocities in root space) and `findBestFrame(features, poseWorld, velocity)` → `{ time, cost }`; `AnimGraphTransition.matchPose?: true` starts the target clip at that time instead of 0 (`graph.ts`, additive). Test: matching the same clip's pose at t returns t ± one sample.
- **Clip compression** (`src/anim/compress.ts`): `compressClip(clip, { positionError, rotationError (rad), scaleError, dropConstant })` removes keyframes a linear fit reproduces within tolerance per channel, drops channels equal to rest, and returns a new `AnimationClip` plus `{ before, after }` byte counts; `quantizeClip(clip, { rotation: 'smallest-three' | 'none' })` packs rotations into `Uint16Array` channels the sampler reads through the existing channel interface (`sampleClip` unchanged for float channels; a `packed` flag on the channel). Tests: sampling a compressed clip stays within tolerance at 100 random times; constant channels dropped; a glTF clip in the fixtures compresses by a reported ratio.
- **Harness**: `harness/anim4.html` + `anim4.ts` + `anim4-state.ts`: `?blend2d` (a 3×3 strafe set of synthetic clips, pad or `?px=&py=` drives it, state `weights`), `?aim` (a target orbiting, state `headYaw`), `?foot` (a figure walking across a stepped floor, state `pelvisY`, `footGap`), `?spring` (a cape chain on a turning figure, state `tipLag`, `?teleport` jumps the figure once), `?match` (two clips crossfading with and without matching, state `startTime`). `e2e/anim4.spec.ts` (E-017 polling), existing anim-graph/ik/skin specs green, `pnpm snap:check` 0 px.
- **Docs**: anim README sections *2D blend*, *Aim offset*, *Foot placement*, *Secondary motion*, *Pose matching*, *Compression*, the *Not here* list trimmed; CHANGELOG block; ARCHITECTURE anim clause (one sentence); root README harness list + count line.
