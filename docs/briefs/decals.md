## Goal

Projected decals: bullet holes, scorch marks, blood, footprints, paint splats, magic circles. A game asks for a decal at a world point with a normal and a size; the decal projects a texture onto whatever geometry is there, fades over a lifetime, and costs one instanced draw for all of them. Two implementations behind one API, chosen by what the renderer has: a **depth-projected box decal** under a depth camera (each decal is a unit box; the fragment reconstructs the world position from the previous frame's depth copy, rejects outside the box, samples the texture by the box's local xy), and a **surface quad** fallback without depth (a camera-independent quad lifted along the normal by `offset`). Rendering only; where to put decals is the game's business.

STATUS row, *done when*: `Decals(renderer, opts: DecalsOptions)` in `src/fx/decals.ts` is a `Drawable`: `DecalsOptions { capacity (default 256), texture: Texture (an atlas), atlas?: { columns, rows } (default 1×1), blend?: 'alpha' | 'multiply' | 'additive' (default alpha), fade?: [number, number] (alpha over normalised age, default [1, 0]), lifetime? (seconds, default Infinity), mode?: 'auto' | 'box' | 'quad' (default auto: box under a depth camera, else quad), offset? (quad lift, default 0.01), normalBias? (box: reject surfaces facing away more than this cos angle, default 0.3), fadeEdge? (box: fade in the last share of the box depth, default 0.2) }`; `decals.add({ x, y, z, nx, ny, nz, size, rotation?, tile?, color?, lifetime? }): number` returns a handle (ring buffer; the oldest is overwritten when full); `remove(handle)`, `clear()`, `count`, `update(dt)` ages and compacts in place (no allocation), `frame.drawable(decals, order)` draws all live decals in one instanced draw (`Mesh` is a unit box or quad, instance buffer written once per frame from a preallocated `Float32Array`; `DECAL_INSTANCE_FLOATS` exported); box mode depth-tests off and depth-writes off (it is a volume); quad mode depth-tests on, writes off; `color` multiplies the texture; `WGSL_DECAL_BOX` and `WGSL_DECAL_QUAD` exported; unit tests (fake GPU: ring buffer overwrite order, `remove` compaction keeps handles stable, mode selection by `frame.depthFormat`, instance float layout, lifetime expiry); harness `decals.html` on the matrix; documented.

## Scope

- `src/fx/decals.ts` + `decals-wgsl.ts`: instances carry the decal's world→local matrix (3×4, like `MATRIX3X4_FLOATS` in render if still exported; otherwise 12 floats inline), tile uv rect, colour, age/lifetime. Box fragment: world position from `invViewProj` × (ndc, depth), transform to local, reject |xyz| > 0.5, uv from local xy, alpha × `fadeEdge` ramp along local z × normal rejection (normal from depth gradient: `dpdx`/`dpdy` of the reconstructed position) × fade by age. Quad fragment: texture × colour × fade. Previous-frame depth copy as particles do (own `depth32float` texture); document that a decal placed this frame appears next frame under box mode.
- Handles: a monotonically increasing id; `remove` marks dead, `update` compacts live instances to the front and keeps an id→slot map (a `Map<number, number>` reset per compaction is fine; no per-frame allocation when nothing died).
- Tests: `decals.test.ts`.
- Harness `harness/decals.html` + `decals.ts` + `decals-state.ts`: a floor and two boxes with a procedurally generated 2×2 atlas (`renderer.textureFromSource` of a canvas: a ring, a splat, a cross, a square); click or the api places a decal at the pointer ray hit (reuse `pick`'s mesh tester or a plane/box intersection in the harness; do not add to `render`); `?mode=box|quad`; state exposes `count`, `mode`, `decalPixel` (probe at the centre of the first decal), `floorPixel` (same floor, no decal), `ages`. `e2e/decals.spec.ts`: `add` then the decal probe differs from the bare floor probe (both modes), `remove` restores it, a short-lifetime decal expires, capacity wraps.
- Docs: fx README *Decals* section, CHANGELOG one line, ARCHITECTURE *FX* one clause, root README harness list item.
