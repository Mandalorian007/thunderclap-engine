## Goal

An animated water surface a 3D game drops into a scene: a planar mesh with a scrolling normal field, Fresnel reflection of the sky colour, sun specular, depth-fade at the shoreline, refraction-free transparency tinted by depth, and foam where the surface meets geometry. Forgewilds-class quality (VISION), no asset, no reflection render pass (a planar reflection camera is a later brief). Rendering only: no buoyancy, no waves-as-physics.

STATUS row, *done when*: `Water(renderer, opts?: WaterOptions)` in `src/fx/water.ts` is a `Drawable`: `WaterOptions { size?: number | [w, d] (plane extent, default 100), segments? (default 1; `displace` needs more), level? (y, default 0), shallowColor, deepColor, depthFade? (world units to full deepColor, default 4), fresnel? (0..1, default 0.6), roughness? (default 0.08), waves?: { scale, speed, amplitude (normal strength), direction: [x, z] }[] (default two layers), foam?: { width (world units from geometry, default 0.4), color } | null, displace?: number (vertex height amplitude, default 0; > 0 moves vertices with the sum of the wave layers), opacity? (default 0.85) }`; every field is live; `water.update(dt)` advances time; `frame.drawable(water, order)` draws it after opaque geometry; under a depth camera it copies the previous frame's `SceneTarget.depth` (like soft particles) and uses it for depth fade, foam and the shoreline tint, writing depth itself so particles and trails sort against it; sun specular and the sky tint come from `frame.lights` (sun direction, colour, fog colour as the horizon reflection; `Sky` present or not); emissive gets the specular highlight so bloom picks it up; `waterHeight(water, x, z, t)` pure function returns the displaced height the shader computes (for a game to float a boat); `WATER_WGSL` exported; `WATER_PARAMS_FLOATS` params block uploaded once per frame; zero per-frame allocation; unit tests (fake GPU: pipeline per depth format, params block layout, `waterHeight` matches the WGSL formula on three samples computed in TS); harness `water.html` on the matrix; documented.

## Scope

- `src/fx/water.ts` + `water-wgsl.ts`: build the plane from `geom` `plane` (import from `../geom`, not a copy) and own a `Mesh`; one bind group: camera block, lights block, params uniform, depth copy texture + comparison-free sampler. Normal field: two or three scrolling layers of analytic gradient noise (use the particles' or sky's hash, or a small inline one); the normal is the sum of the layer gradients, strength by `amplitude`. Shading: `fresnel` lerp between the tinted refraction colour (shallow → deep by linear depth difference from the depth copy) and the reflection colour (sky gradient approximation from `lights.fog.color` and a zenith blend, plus the sun highlight by `roughness`), then `opacity`. Foam: when depth difference < `foam.width`, mix `foam.color` with a noise mask. Without a depth camera: no depth copy, depth fade off, foam off, documented.
- `displace > 0`: the vertex shader offsets y by the summed layers; `segments` must be > 1 for it to show; `waterHeight` mirrors it on the CPU.
- Tests: `water.test.ts`.
- Harness `harness/water.html` + `water.ts` + `water-state.ts`: a pool of water in a basin of boxes (geom `box`) with a sloped ramp that enters the water, `Sky` behind, sun moving slowly (`?still` parks it); state exposes `shorelinePixel` (a probe on the ramp just below the surface), `deepPixel`, `foamPixel`, `specularPixel`, `height` (`waterHeight` at a fixed point), `t`. `e2e/water.spec.ts`: the shoreline probe is closer to `shallowColor` than the deep probe is; foam probe brighter than its neighbour below; specular probe emissive > 0 with `?still`; `height` changes between two reads.
- Docs: fx README *Water* section (options, depth copy caveat: previous frame, like soft particles), CHANGELOG one line, ARCHITECTURE *FX* one clause, root README harness list item.
