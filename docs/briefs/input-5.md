## Goal

The input pieces an action game hits in its first week: action contexts so a menu, gameplay and a vehicle each own their bindings without the game toggling `blocked`, an input buffer so a press a few frames early still lands, a shaped stick read, gyro aim on phones, a tap hook on `Look`, and recordings that replay every pointer. Everything stays intent, never mechanics: the engine says "attack was pressed 80 ms ago", the game decides whether that starts a combo.

STATUS row, *done when*:

- **Action contexts**: `input.pushContext(name, { bindings?: Partial<BindingMap>, pass?: 'none' | 'unbound' | 'all' })` → remover, `input.popContext(name)`, `input.context` (top name), `input.onContextChange(fn)`. The top context's bindings win; `pass: 'unbound'` (default) lets actions it does not bind fall through to the context below, `'none'` silences them, `'all'` overlays. A push or pop resets hold progress and tap counts for every action whose effective binding changed (as `blocked()` does today) so a held key never fires across the change. `rebind`, `bindings()` and `glyphFor` act on the top context (documented). Tests: a menu context over gameplay silences `attack` with `pass: 'none'` and lets it through with `'unbound'`; a key held through a push does not fire `pressed` in the new context; popping restores the old binding and glyph.
- **Input buffer**: `input.buffered(action, windowMs)` true if the action went `pressed` within the last `windowMs` and that press was not yet consumed; `input.consume(action)` marks the latest press used (also clears `pressed` for the rest of the tick). Counted in ticks from the existing tick clock (`ceil(windowMs / tickMs)`), deterministic under record/replay. Tests: a press 3 ticks before a `buffered(a, 100)` call at 60 Hz is true, at 7 ticks false; a consumed press is not returned twice; replay gives the same answers.
- **Stick read**: `input.stick(negX, posX, negY, posY, out, { deadzone = 0.15, shape: 'radial' | 'axial' | 'scaledRadial' = 'scaledRadial', curve = 1, clamp = true })` → `out` (a `[x, y]` the caller owns, no allocation), reading the four actions' analog values so keys, pad sticks and touch-zone sticks all go through it; `input.stickAngle(out)` helper for aim (atan2, null-safe under the deadzone). `Look`'s internal pad deadzone uses the same function (behaviour unchanged at the default). Tests: each shape's output at a few known inputs; scaledRadial is continuous at the deadzone edge; diagonal keys give length 1, not √2.
- **Gyro aim**: `createGyroSource({ sensitivity, invertY?, smoothing? })` (`src/input/gyro.ts`) reading `deviceorientation`/`devicemotion` rotation rate into a look delta, `requestPermission()` (iOS needs a user gesture: resolves `'granted' | 'denied' | 'unavailable'`), `enabled`, `dispose()`; `Look` gains `gyro?: GyroSource` added to the pointer/stick delta each tick. Feature-detected; a fake event source for tests and the harness (no real sensor in CI). Tests: a fake rotation rate yields the expected yaw/pitch delta at a sensitivity; `unavailable` with no API; `Look` sums gyro and stick.
- **Look tap**: `look.onTap(fn: (x, y, device) => void)` → remover, fired on a primary press-release under the pan threshold and tap time on a pointer the look claimed (orbit/drag mode) or on any canvas pointer in locked mode, with screen coordinates in the router's units. Test: a short click fires once, a drag does not, a held press past the tap time does not.
- **Record all pointers**: `InputTickEvents` gains an extra-pointer lane (id, kind, x, y, buttons, phase) so touch zones, gestures and a second thumb replay; old recordings without it still parse (version field bumped, reader accepts both). Context pushes/pops and `consume` calls are recorded so a buffered replay is identical. Tests: a two-thumb touch-zone session records and replays to identical action states; a v1 recording still plays.
- **Harness**: `harness/input5.html` + `input5.ts` + `input5-state.ts`: `?contexts` (gameplay + a menu pushed at t=1 s; state `context`, `attackFired`), `?buffer` (a scripted press 3 ticks early; state `buffered`, `consumed`), `?stick` (a fake pad driving the three shapes as dots; state per shape `[x, y]`), `?gyro` (fake rotation rate turning a camera; state `yaw`, `pitch`), `?tap` (orbit look with a tap marker; state `taps`), `?replay` (records two thumbs then replays; state `match: boolean`), `?still` parks. `e2e/input5.spec.ts` (E-017 polling), existing input/gestures/look/record specs green, `pnpm snap:check` 0 px.
- **Docs**: input README sections *Contexts*, *Input buffer*, *Sticks*, *Gyro aim*, *Look tap*, the recording version note; types list; CHANGELOG block; ARCHITECTURE input clause (one sentence); root README harness list + count line.
