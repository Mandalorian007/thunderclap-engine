## Goal

The audio a 3D action game is missing after zones and sends: occlusion that a game answers with one ray callback, Doppler on moving emitters, per-voice filters, audio sprites (one buffer, many named ranges) and streamed music for long tracks, plus the small debts the last three audio workstreams left. WebAudio only, every new node pooled and faked, nothing in `src/audio` imports outside `audio/` and `core/` (the `Transform` read is a structural type, not an import from `render`).

STATUS row, *done when*:

- **Occlusion** (`src/audio/occlusion.ts`): `audio.occlusion = { probe: (listener, emitter, out: { amount: number }) => void, interval?: number }` (`amount` 0 clear .. 1 fully occluded; a game answers it with a ray against its own world, the engine never casts); each spatial voice owns a lowpass (`BiquadFilterNode`, pooled like panners) whose cutoff ramps between `openCutoff` (default 20 kHz) and `closedCutoff` (default 600 Hz) and gain between 1 and `closedGain` (default 0.4), probed round-robin so no more than `budget` voices (default 8) probe per `update`; `SpatialOptions.occlude?: boolean` (default true when a probe is set); `Voice.occlusion` reads the last amount. Tests on the fake context: a probe returning 1 drives the cutoff down over `interval`; voices past the budget probe on the next update; no probe set means no filter node is created (node count unchanged from today).
- **Doppler** (`audio.ts`): `SpatialOptions.doppler?: number` (factor, 0 off = today) with the listener and emitter velocities derived from successive `setPosition`/`listener.set` calls per `update(dt)` (no allocation; a teleport larger than `maxDopplerSpeed × dt` resets instead of chirping); applied as a `playbackRate` multiplier on top of `setRate`. Tests: an emitter approaching at 10 m/s raises the rate by the textbook ratio; a teleport leaves the rate at `setRate`'s value.
- **Per-voice filter**: `Voice.filter(kind: 'lowpass' | 'highpass' | 'bandpass' | null, { cutoff, q, ramp })` inserts or removes one pooled biquad between the voice gain and the panner/bus (shares the pool with occlusion: an occluded voice with a user filter has two nodes, documented). Test: the chain order on the fake context.
- **Audio sprites** (`src/audio/sprites.ts`): `audio.defineSprites(name, { buffer | url, sprites: { hit: [startMs, lengthMs], ... }, loopPoints? })` so `play('name#hit')` (or `play({ sprite: 'name', clip: 'hit' })`: pick one, document) plays a range of one buffer with the same `Voice` surface, `loop` honouring `loopPoints`; a JSON sidecar shape `{ src, sprites }` loads through `src/assets` with no new loader kind (document the call, additive paragraph in the assets README if needed). Tests: a sprite voice schedules `start(when, offset, duration)` with the right numbers; an unknown clip throws a readable error.
- **Streamed music** (`music.ts`): `music.play(name, { stream: true })` uses a `MediaElementAudioSourceNode` over an `<audio>` element instead of decoding the whole file (long tracks on phones); the beat grid, stems ducking and crossfades keep working with a `currentTime`-derived clock; falls back to the buffer path where `createMediaElementSource` is missing. Test with a fake element: the grid origin comes from the element's time; the crossfade ramps both.
- **Debts**: `Voice.sendCount` on the interface (and on the adapter below); `createVoiceAdapter(audio, { source: AudioNode, bus, onEnd })` → a `Voice` another raw-source owner registers (`audio.register` accepts it; zones ambients use it, additive edit in `zones.ts`); `audio.background(hidden: boolean)` as the lifecycle flag distinct from user `suspend()`/`pause()` (a hidden flag suspends the context and restores whatever user state was set; `attach({ pauseWhenHidden })` routes through it) and host-mobile's lifecycle calls it (one-line additive edit, name the file and line); `Transform.changed` (a monotonic counter bumped by the setters, read-only) and `Voice.follow` skipping the matrix read when it is unchanged (test: a follower under a parked transform calls `setPosition` zero times after the first update); `e2e/music.spec.ts:125` asserts the ramp direction with a wider budget.
- **Harness**: `harness/audio4.html` + `audio4.ts` + `audio4-state.ts`: `?occlude` (an emitter behind a wall the camera orbits; the probe is a segment-vs-box test in the page; state `occlusion`, `cutoff`), `?doppler` (an emitter passing the listener; state `rate`), `?sprites` (three clips of one synthesised buffer on keys 1-3; state `lastClip`, `voices`), `?stream` (a synthesised long track as a Blob URL streamed; state `grid.bar`, `streaming`), `?still` parks. `e2e/audio4.spec.ts` (E-017 polling, audio unlock through a synthetic click as `music.spec` does), existing music/zones specs green, `pnpm snap:check` 0 px.
