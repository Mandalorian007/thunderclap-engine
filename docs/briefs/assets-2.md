## Goal

The loading layer every shipped game writes itself: a typed asset manifest, a bundle that loads it with progress, concurrency, cancellation, caching and per-asset error reporting, and a runtime sprite atlas packer so a 2D game's loose images become one texture with uv rects. The engine never fetches: the bundle takes a `read(uri) → Promise<ArrayBuffer | Blob | ImageBitmap>` the game supplies (its `fetch`, a zip reader, an Electron file read). Decoding is the engine's job: images through `createImageBitmap`, audio through the mixer's context, glTF through `parseGltf`/`loadGltf`, JSON/text directly.

STATUS row, *done when*: `defineManifest(entries)` is identity with types: `ManifestEntry = { kind: 'texture', uri, options?: LoadTextureOptions } | { kind: 'texture-array', uris[], options? } | { kind: 'gltf', uri, resources?: Record<string, string> (uri → uri), options?: LoadGltfOptions } | { kind: 'audio', uri } | { kind: 'json', uri } | { kind: 'text', uri } | { kind: 'bytes', uri } | { kind: 'image', uri } (an `ImageBitmap`, for atlases) | { kind: 'atlas', uris: Record<name, uri>, options?: AtlasOptions }`; `createBundle(manifest, { read, renderer?, audio?, concurrency? (default 4), retries? (default 0), priority?: (key) => number })` → `Bundle<M> { load(keys?: (keyof M)[]): Promise<void>, get<K>(key): AssetOf<M[K]> (throws if not loaded), has(key), progress: { loaded, total, bytes, bytesTotal? (from read's reported sizes when it returns `{ bytes, total }`), fraction }, on('progress' | 'asset' | 'error' | 'done', cb) → unsub, cancel(), errors: BundleError[] (per key, with the cause; a failed asset does not fail `load` unless `strict: true`), release(key?) (destroys GPU textures and glTF scenes it created), dispose() }`; the same uri requested by two entries is read once; `packAtlas(images: Record<name, ImageBitmap | ImageData | { width, height, data }>, opts?: AtlasOptions { padding? (default 1), maxSize? (default 4096), powerOfTwo? (default true), extrude? (default 1; copies edge pixels into the padding), sort? }) → AtlasLayout { width, height, rects: Record<name, { x, y, w, h, u0, v0, u1, v1 }>, draw(ctx: CanvasRenderingContext2D | OffscreenCanvasRenderingContext2D) }` (shelf/skyline packing, deterministic for the same input order after sorting by height); `createAtlasTexture(device, layout, images, opts?)` draws into an `OffscreenCanvas` and calls `loadTexture` → `{ texture, rects }`; in Node tests the packer runs against `{ width, height, data }` sources and `draw` is covered with a fake 2D context; unit tests; harness `assets.html` on the matrix; documented.

## Scope

- `src/assets/manifest.ts` (types + `defineManifest`), `src/assets/bundle.ts` (loader: a small priority queue, `concurrency` in-flight reads, `AbortController`-style cancel via a `cancelled` flag checked between steps; progress counts assets and bytes; `Texture` from `loadTexture(renderer.device, bitmap, options)`; `gltf` entries: `read` the main uri, `parseGltf`, then `read` every `doc.externalUris` through the entry's `resources` map (or the uri itself when unmapped) and pass them to `loadGltf` as `resources`; `audio` entries need `audio` (an `AudioEngine` or anything with `context.decodeAudioData`), else the error names it), `src/assets/atlas.ts` (packer + canvas draw + `createAtlasTexture`).
- `read` contract documented: returns `ArrayBuffer`, `Blob`, `ImageBitmap`, or `{ data, total? }` for byte-progress; the bundle never calls `fetch`, `XMLHttpRequest` or `Image` with a url (a `Blob` → `createImageBitmap(blob)`; bytes → `new Blob([bytes])` first).
- Tests: `bundle.test.ts` (fake `read` with delays: concurrency never exceeded, progress monotonic and ends at 1, cancel stops further reads, dedupe of shared uris, per-key errors with `strict` off/on, `release` calls `destroy`), `atlas.test.ts` (rects non-overlapping and inside the atlas, padding respected, uv rects match px rects, power-of-two sizing, overflow past `maxSize` throws naming the image, determinism), `manifest.test.ts` (type-level `AssetOf` through `expectTypeOf` if vitest's is available, else a compile-only test).
- Harness `harness/assets.html` + `assets.ts` + `assets-state.ts`: a manifest of 12 entries served from an in-memory `Map<uri, ArrayBuffer | Blob>` built at startup (PNG blobs drawn on a canvas, a glb from `gltf-writer.ts`, a WAV generated in TS, a JSON and a text), `read` delays each by 50–200 ms with `?slow`; a progress bar (ui `bar` if ws/ui-widgets has landed, else a div); the atlas drawn as sprites with the 2D renderer using the packed uv rects; state exposes `progress`, `loaded`, `errors`, `atlasSize`, `rectCount`, `spritePixel` (a probe on one atlas sprite), `done`. `e2e/assets.spec.ts`: progress reaches 1 and `done` fires, `?fail=one` reports one error and still finishes, the sprite probe is the sprite's colour, `?cancel` stops below 1.
- Docs: assets README *Bundles* and *Atlas* sections (with the `read` contract and the no-network rule), CHANGELOG one line, ARCHITECTURE *Assets* one sentence, root README harness list item.
