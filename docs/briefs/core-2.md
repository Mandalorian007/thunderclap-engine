## Goal

The small deterministic utilities a game reaches for in its first hour, in one place with one convention: a seeded random with named streams, value and gradient noise, a scheduler for delayed and repeating calls that runs on the game's own `dt`, a typed object pool, and scenes that can preload asynchronously and transition. Pure TypeScript, allocation-free in steady state, nothing in `core` imports outside `core`.

STATUS row, *done when*:

- **Random** (`src/core/random.ts`): `createRandom(seed: number | string)` → `Random` with `next()` (float [0,1)), `int(min, max)`, `float(min, max)`, `bool(p)`, `pick(array)`, `weighted(weights)`, `shuffle(array)` (in place), `gaussian(mean, sd)`, `unitVec2(out)`, `unitVec3(out)`, `fork(name)` (a child stream derived from the seed and the name, so order of use in one stream never changes another), `state` get/set (a `Uint32Array(4)` for save/replay). xoshiro128** or sfc32, documented; string seeds hashed with a documented FNV-1a. Tests: a seed replays byte-identical sequences; `fork('a')` is independent of calls on the parent; `shuffle` is unbiased over 10k runs within 2% on 4 elements; `state` round-trips.
- **Noise** (`src/core/noise.ts`): `createNoise(seed)` → `{ value2(x, y), value3(x, y, z), perlin2, perlin3, simplex2, simplex3, fbm(fn, x, y, z?, { octaves, lacunarity, gain }) }` all in [-1, 1], seeded permutation table, no allocation per call. Tests: continuity (adjacent samples differ by less than a bound), range, determinism per seed, `fbm` with one octave equals the base.
- **Scheduler** (`src/core/timer.ts`): `createScheduler()` → `after(seconds, fn)` → handle, `every(seconds, fn, { count? })`, `cooldown(name, seconds)` → `{ ready: boolean, remaining, use(): boolean }`, `update(dt)`, `cancel(handle)`, `clear()`, `pause()`/`resume()`; handles are integers from a pool, fires are in due order, a callback that schedules during `update` runs next tick, no closures allocated per update. Tests: order of fires; `every` with `count`; a cooldown `use()` returns false until ready; `pause` holds remaining time.
- **Pool** (`src/core/pool.ts`): `createPool<T>({ create, reset?, initial, max? })` → `acquire()`, `release(item)`, `size`, `live`, `forEach(fn)` (live items only, no allocation), `drain()`; past `max` `acquire` returns `undefined` (documented) so a game caps its effects. Tests: reuse order, cap, `forEach` sees only live.
- **Scene preload and transitions** (`src/core/scene.ts`, additive): `Scene.preload?(ctx): Promise<void>` runs before `enter` while the previous scene keeps rendering; `SceneStack.push/replace` return a `Promise<void>` resolving when the scene is entered (sync scenes resolve next tick); `SceneStack.onTransition(fn: (from, to, phase: 'preload' | 'enter' | 'exit') => void)` so a game drives `ui.loading` or a fade from one hook; `SceneStack.transitioning: boolean`; errors in `preload` reject the promise and leave the stack unchanged. Tests: a slow preload keeps the old scene's `update` running; the promise resolves after `enter`; a rejected preload leaves the stack as it was.
- **Harness**: `harness/core2.html` + `core2.ts` + `core2-state.ts`: `?random` (a scatter of 2k points from two forked streams, state `checksum` of the first 100 values), `?noise` (a canvas-sized fbm field, state `min`, `max`, `checksum`), `?timer` (a scheduler driving blinks and a cooldown bar, state `fires`, `cooldownReady`), `?preload` (a scene push with a 1 s preload under a loading screen, state `phase`, `oldSceneFrames`), `?still` parks. `e2e/core2.spec.ts` (E-017 polling: the checksums are the determinism assertion), `e2e/game.spec.ts` green, `pnpm snap:check` 0 px.
