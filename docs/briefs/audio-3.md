## Goal

The mixer sees everything that plays and a game can route any single voice through an effect. Three small additions to `AudioEngine`, one hook so music stems count as voices, and a pause recipe built from them. Nothing changes for callers who do not use the new members; the fake-context tests stay green.

STATUS row, *done when*:

- `mixer.voices(bus?: BusName): readonly Voice[]` returns the live voices (playing, not yet ended) on a bus, or all; `voiceCount` is `voices().length`; a stopped or ended voice leaves the list the same frame its node ends (`onended`) or `stop` is called; allocates one array per call (document it; a `forEachVoice(bus, fn)` variant that allocates nothing is welcome).
- `Voice.sendTo(input: AudioNode | Send, amount: number, ramp?: number): void` adds a parallel path from the voice's post-gain node through a per-voice send gain into `input` (`Send.input` or any node); `amount` 0 removes it (disconnect, free the gain); at most 4 sends per voice (throw beyond); torn down with the voice; the inert voice and variations' `SILENT` voice implement it as a no-op. Document the occlusion recipe: a wall between listener and source → `voice.sendTo(muffle, 1)` and `voice.setGain(0.3)`, both ramped, in the game's own occlusion test.
- `mixer.register(voiceLike: Voice, bus: BusName): () => void` adds an externally owned voice to the mixer's books so `voices`, `voiceCount`, `stopAll` and the zones/ducker code that iterates voices see it; returns the unregister. `createMusic` registers each playing stem through it as a `Voice` adapter (`stop(fade)` fades the stem, `setGain` sets the stem gain, `setRate` sets `playbackRate`, spatial members are no-ops, `playing` tracks the source) so `audio.stopAll()` now also stops music **unless** called as `stopAll({ except: ['music'] })` (new optional filter; default behaviour is to stop everything, documented as a change in the CHANGELOG with the migration line).
- **Pause recipe**: `audio.pause(opts?: { keep?: BusName[] })` / `audio.unpause()` on the engine: ramps every bus except `keep` (default `['ui']`) to silence over 50 ms and sets `voice.setRate` on affected voices to 0 where the browser allows it (else leaves rate and just mutes; say which path ran through `audio.paused: boolean` and a `pausedBuses` list); `unpause` restores the previous bus volumes and rates. Does not touch the context state (that is `suspend`). Music stems pause the same way through their adapters.
- **Tests (fake context):** `voices('sfx')` lists exactly the live sfx voices and drops an ended one; `sendTo` builds one gain and connects it to the send's input, `sendTo(x, 0)` disconnects, the fifth send throws; `register` makes a fake voice visible to `voiceCount`/`stopAll` and unregister hides it; music stems appear in `voices('music')` while playing and vanish on stop; `stopAll({ except: ['music'] })` leaves them; `pause` ramps the right buses and `unpause` restores exact values; variations `SILENT` and the inert voice accept `sendTo` without throwing.
- **Harness:** extend `harness/audio.ts` (or `spatial-audio`) state with `voices` (per bus counts), `sends` (count on the probe voice), `paused`; `e2e/audio.spec.ts` (or the spatial one) gains: play two sfx, counts show 2; `?pause` ramps sfx to 0 and ui stays; one stem playing shows under `music`. No new harness page unless neither existing audio page can host it.
