## Goal

Close the input wishes that games keep re-writing: a third-person orbit on `Look` without pointer lock, player-rebindable actions with persistence, chords and hold/double-tap triggers on actions, a pan observer so a slow drag never turns into a long-press, pad rumble, and an "any device" prompt glyph API so a HUD can say "press [A]" or "tap" correctly. Everything records and plays back through `record.ts` so the e2e harness stays deterministic.

STATUS row, *done when*:

- **`Look` orbit mode**: `LookOptions.mode?: 'locked' | 'orbit'` (default `'locked'`, today's behaviour). `'orbit'`: a mouse or pen drag on the attached element rotates yaw/pitch with the same `sensitivity` (no pointer lock requested, `lockOnFirstClick` ignored and warned once), touch look zone unchanged, wheel and pinch still zoom, a `Look.setMode()` switch at runtime (a third-person game toggles into `'locked'` for aim). Orbit drags do not reach `Gestures` as pans when the same element has both: `Look` claims the pointer through the existing `Input` arbitration or a documented `claimPointer` hook; say which. Tests: drag yaw/pitch, sensitivity, mode switch mid-drag, no `requestPointerLock` call in orbit mode, blocked() zeroes.
- **Rebinding**: `Input.rebind(action, bindings)` replaces an action's bindings at runtime; `Input.bindings()` returns the current map; `Input.listen(action) → Promise<Binding>` captures the next key, pad button, pointer button or XR button pressed (Escape cancels, text-entry targets ignored, a timeout option) for a settings screen; `serializeBindings(map)` / `parseBindings(text, defaults)` (JSON, unknown actions dropped with a warning, missing actions filled from defaults) for `save`; a conflict report `findConflicts(map) → { binding, actions[] }[]`. Tests on every path including an action rebound while held (release still lands on the old action's `released`).
- **Triggers**: `Binding` gains optional `trigger?: 'press' | 'hold' | 'doubleTap'` with `holdMs` (default 400) and `doubleTapMs` (default 300), and `chord?: Binding[]` (all down, in any order, fires once); `ActionState` gains `holdProgress` (0..1 while a hold binding is down). Deterministic on the `Input.update` clock so `record.ts` replays them identically (add one replay test of a hold and a chord).
- **Gestures pan observer**: `GestureOptions.onPanCandidate?(pointer, travel)` or a `pan: 'prefer'` option so travel past a fraction of `panThreshold` cancels the long-press timer before `checkLongPress` can fire; fix the ordering at ~339/~536 so a slow drag under a long frame becomes a pan, never a long-press; a regression test with a fake clock reproducing the ws/flake-input scenario (3 px, 500 ms gap, 12 px) must report pan.
- **Rumble**: `Input.rumble({ strong, weak, ms, pad? })` through `gamepad.vibrationActuator.playEffect('dual-rumble', …)` when present, no-op otherwise; `Input.rumbleSupported(pad?)`; recorded as an event in `record.ts` so playback can assert it fired (ticks carry it as `rumble`). Tests with a fake actuator.
- **Prompt glyphs**: `Input.lastDevice: InputDevice | 'xr'` (updated on every real event, not on playback unless the tick says so), `Input.on('device', …)`; `glyphFor(action, device?) → { kind: 'key' | 'button' | 'axis' | 'pointer' | 'gesture' | 'xr', label: string }` with pad labels by layout (`'xbox' | 'playstation' | 'nintendo' | 'generic'` guessed from `gamepad.id`, overridable), key labels through `KeyboardEvent.code` → display name table (arrows, space, modifiers, letters, digits), gestures as `'tap'`/`'drag'`/`'pinch'`, XR as `'trigger'`/`'squeeze'`/`'pinch'`; the ui module may later render these (do not touch `src/ui`). Tests on the mapping tables and the device switch.
- **Harness** `harness/input.html` gains `?orbit` (a `Look` in orbit mode on a cube), a rebinding panel (press a key to rebind `jump`, conflicts listed), hold and chord indicators, a device glyph readout; state exposes `yaw`, `pitch`, `locked`, `bindings` (serialised), `holdProgress`, `chordFired`, `lastDevice`, `glyph`, `rumbles`, `panOrLong` (last gesture kind). `e2e/input.spec.ts` adds: orbit drag changes `yaw` on desktop and touch rows without `locked` becoming true; rebind flow via keyboard; hold fires at ≥ 400 ms and not at 200 ms; chord fires once; the slow-drag sequence reports `pan`; `lastDevice` flips keyboard → mouse → keyboard; `glyph` for `jump` reads `Space` on keyboard rows. `e2e/replay.spec.ts` unchanged and green; `pnpm snap:check` 0 px.
