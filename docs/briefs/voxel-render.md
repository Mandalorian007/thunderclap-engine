# Brief: ws/voxel-render

Read `docs/briefs/common.md` first, then `docs/VISION.md` pillar 2 (voxel games trivial: the engine ships the mesher, the chunk grid and the picking, the game ships the blocks), the ws/demo-voxel row and its wishes in `docs/STATUS.md` (this brief closes every one of them), `demos/voxel/mesher.worker.ts` (greedy mesher + 4-neighbour AO bake: lift it, do not edit the demo), `demos/voxel/world.ts` (`raycastVoxels` DDA), `demos/voxel/main.ts` (the chunk frustum loop, the `BLOCKS_WGSL` prelude reading `layer = u32(round(color.a))`, the `fract` + `textureSampleGrad` wrap, the second water view; the README *Known limits* riser-triangle artefact), `src/render/mesh.ts` (`VERTEX_LAYOUT_3D`, `MeshDesc.capacity`, `Mesh.update`, `growths`: capacity exists; the wish is a `slack` convenience and transferable-buffer input), `src/render/texture.ts` (sampler kinds: where `nearest-mip-repeat` goes), `src/render/camera.ts` (`seesSphere`; read only), `src/fx/water.ts` (`WaterOptions`: add an origin), `src/fx/sky.ts` (night ambient floor), `src/geom/README.md` (module shape to copy for a new pure module), `harness/mesh*.ts`, `e2e/mesh.spec.ts`.

## Goal

`@thunderclap/engine/voxel`: a new noun-free module that turns a block grid into chunk meshes on a worker or the main thread, culls and draws them, picks blocks with a ray, and ships the vertex convention and WGSL prelude a block material needs. The voxel demo would shrink by three files once it adopts it (a later brief does that; this one does not touch `demos/`).

STATUS row, *done when*:

- **Grid** (`src/voxel/grid.ts`): `createVoxelGrid({ sizeX, sizeY, sizeZ, chunk: 16 })` over a `Uint8Array` (0 = air), `get/set(x, y, z)`, `setMany(...)`, per-chunk dirty flags and `version`, `chunkAt(x, y, z)`, `forEachDirtyChunk(fn)`, `serialize()/deserialize()` to one transferable `ArrayBuffer` (so a worker owns a copy). Tests.
- **Mesher** (`src/voxel/mesher.ts`): `meshChunk(grid, cx, cy, cz, opts, out) → { vertices, indices, vertexCount, indexCount }` greedy-merged quads with the demo's AO bake (`ao: boolean`, 4-neighbour corner rule), `VERTEX_LAYOUT_3D` output with colour.rgb = AO and colour.a = texture-array layer by a `layerOf(block, face) → number` callback, correct winding on every face (write the test that would have caught the demo's riser-triangle artefact: every quad planar, outward, both triangles on the same side; then fix the cause if it is in the mesher, else document what the draw side does), `out` buffers grown with slack and reused. Pure, usable in a worker. Tests against a brute-force exposed-face count on random grids and the hand-checked 1-block step.
- **Worker bridge** (`src/voxel/mesher-worker.ts` + `worker-client.ts`): the mesher behind `createVoxelMesher({ worker?: Worker })`: `remesh(chunkIndex) → Promise<ChunkMesh>` with transferable replies, coalescing repeat requests per chunk, an in-thread fallback when no `Worker`. Tests on the client with a fake worker.
- **Chunk renderer** (`src/voxel/chunks.ts`): `createVoxelChunks(renderer, grid, { material, slack: 1.5 })` → a `Drawable` owning one `Mesh` per non-empty chunk created with `capacity` × `slack` (so the first edit does not hit the grow path: test `growths` stays 0 after place + break), a bounding sphere per chunk, `draw()` culling with `camera.seesSphere` and reporting `{ drawn, culled, triangles }`, `update()` pulling finished remeshes, `dispose()`. Tests with the fake GPU.
- **Picking** (`src/voxel/ray.ts`): `raycastVoxels(grid, ox, oy, oz, dx, dy, dz, maxDist, out) → boolean` DDA with hit cell, hit face normal and the adjacent empty cell (place target). Tests on axis rays, diagonal rays, miss.
- **Material prelude**: `VOXEL_WGSL` string exporting `voxel_layer(color) → u32` and `voxel_uv_wrap(uv)` for the `fract` + `textureSampleGrad` recipe, and a `nearest-mip-repeat` sampler kind in `src/render/texture.ts` so a block material does not need the wrap by hand (keep the prelude for shaders that want it). Test: the sampler kind maps to `repeat` address modes with nearest mag/min and linear mipmaps.
- **Water origin**: `WaterOptions.origin?: [x, y, z]` (default `[0, 0, 0]`, today's) so a world is not centred on it. Test: the plane's transform moves. **Sky night floor**: `SkyOptions.ambientFloor` (default today's value, so the showroom and arena stay identical) documented as the knob the demo wished for.
- **Harness** `harness/voxel.html` + `voxel.ts` + `voxel-state.ts`: a 4×2×4 chunk procedural world, pointer-lock look, click breaks, right-click places, `?still`; state exposes `chunks`, `drawn`, `culled`, `triangles`, `growths`, `remeshMs`, `hit`. `e2e/voxel.spec.ts`: boot with `drawn + culled === chunks`, turning the camera changes `drawn`, a click at the centre sets `hit` and reduces `triangles` or changes it, `growths` is 0 after place + break; `pnpm snap:check` 0 px.
- **Docs**: `src/voxel/README.md` (layout table, convention, worker recipe, the demo migration recipe), package `exports` + `ARCHITECTURE.md` subpath list, CHANGELOG block, root README harness item + count line.
