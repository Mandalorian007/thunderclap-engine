## Goal

The four templates track the engine they are meant to teach: every hand-rolled helper the engine has since shipped is replaced by the engine call, each template's `CLAUDE.md` names the engine surface instead of the local workaround, and the line count drops with no behaviour change. Then the one thing the templates still lack: a Playwright smoke per template so a generated game is proven to boot, not just typecheck.
