## Goal

The UI layer stops making each widget solve projection and pad ownership on its own: one anchors frame every world-anchored widget reads, one "the modal has the pad" latch on the stack that the cursor, PadNav and a game's own bindings share, and world panels driven from the input tick instead of the game loop. Plus the UI pieces a 3D action HUD still lacks: a damage/float number pool, a radial progress ring, a compass strip and a minimap widget fed by the game's own positions. Everything DOM or canvas, no new ties outside `ui`, `input` (types only) and `core`.

STATUS row, *done when*:

- **Anchors frame**: `Anchors.frame: { width, height, rect }` (the logical size and CSS rect it projects into, updated on `place`); `ui.tooltip` and `ui.cursor` read it instead of carrying their own `rect`/`frame`/`units` (the old options stay accepted and deprecated, one README line each); a world-target tooltip and the world cursor project through the same call (`anchors.project(x, y, z, out)` public if it is not). Tests: a tooltip on a world target lands where `anchors.place` puts an anchored element; resizing the surface moves both.
- **Modal yields pad**: `PanelStack.padOwner: 'stack' | 'game'` (read-only getter, `'stack'` while any modal is open) and `stack.onPadOwnerChange(fn)` (fires on the transition, returns the remover); `PadNav` and `ui.cursor` subscribe to it instead of polling `isModal` each frame (both latches reset on the transition, as today); `createGame` exposes `ui.padOwner` so a game's own bindings can gate on it. Tests: opening a modal flips the owner once and resets the cursor latch; closing it fires once; two cursors share one transition.
- **World panel on the input tick**: `createWorldPanel` gains `attach(input)` that registers `poll(router.pointers)` through `input.onUpdated` and `update(camera)` through the game's `afterUpdate` or the renderer's frame hook (name which; the panel README says "call `attach(ctx.input)` once" and the manual `poll`/`update` path stays); `detach()`. `harness/world-panel.ts` uses `attach`. Test: a pointer press reaches the panel without the page calling `poll`.
- **Float numbers** (`src/ui/float-numbers.ts`): `ui.floats = createFloatNumbers(anchors, { max: 64, duration, rise, style })` → `floats.spawn(x, y, z, text, { kind })` (pooled DOM nodes, transform-only animation, kinds map to theme classes: `'damage' | 'heal' | 'crit' | 'info'`), `update(dt)`, `clear()`; a spawn past `max` recycles the oldest. Tests: 100 spawns keep 64 nodes; a spawned node is gone after `duration`.
- **Radial progress and compass** (`src/ui/widgets-3.ts`): `ui.ring({ radius, thickness, value, label })` (conic-gradient or SVG arc, `set(value)`, `setLabel`), `ui.compass({ width, headingDeg, markers: [{ name, bearingDeg, icon? }] })` (a strip that scrolls with `setHeading`, markers placed by bearing difference, wrap-around). Tests: ring at 0.25 exposes `aria-valuenow`; a marker at +90° sits right of centre by width/4 at a 180° field of view.
- **Minimap** (`src/ui/minimap.ts`): `ui.minimap({ size, worldRadius, rotate: boolean, background?: image | canvas })` with `setCenter(x, z, headingDeg)`, `setMarker(id, x, z, { kind, icon? })`, `removeMarker(id)`, `clear()`; markers are pooled DOM nodes transformed into the circle (clamped to the rim when outside `worldRadius` with an `outside` class), the background is a canvas the game paints (the engine never knows the map). Tests: a marker at `worldRadius × 2` clamps to the rim; `rotate: true` turns a marker at bearing 90 to the top when heading is 90.
- **Harness**: `harness/ui4.html` + `ui4.ts` + `ui4-state.ts`: `?floats` (clicks spawn numbers over a spinning cube; state `live`, `pooled`), `?ring` (a ring filling over 3 s; state `value`), `?compass` (a camera orbiting; state `heading`, `markers`), `?minimap` (four markers and a moving centre; state `onRim`), `?modal` (a modal opens at t=1 s with a cursor and PadNav live; state `padOwner`, `cursorLatched`), `?still` parks. `e2e/ui4.spec.ts` (E-017 polling), existing ui/world-panel/anchors specs green, `pnpm snap:check` 0 px.
- **Docs**: ui README sections *Anchors frame*, *Pad owner*, *World panels on the input tick*, *Float numbers*, *Ring and compass*, *Minimap*, the deprecations; types list; CHANGELOG block; ARCHITECTURE ui clause (one sentence); root README harness list + count line.
