## Goal

The arpg demo throws away and recreates widgets the engine should move or resize itself. This brief closes three of adoption-5's wishes and one ui backlog line.

The STATUS row is done when:

- **Meter placement can change.** A `ui.meter` handle gains `setPlace(place)`, which moves the live widget between regions or rails without losing its value, trail or theme. Alternatively, a meter accepts a per-form-factor place map, in the same shape ui-10 used for meter size. Pick one and say why in the README.
  - Test: moving a meter keeps its value and its trail state.
  - Test: no node is leaked when a meter moves.
- **The minimap holds its size in a content rail.** A minimap inside a content rail no longer shrinks to fit the rail it is measured in. It holds `size` and the rail grows to fit it, so the demo-side `min-width` is no longer needed.
  - Test: a 100 px minimap in a rail measures 100 px.
- **`meter.size` getter** (ui backlog).
- **Docs:** ui README, the types list, one CHANGELOG line, and one ARCHITECTURE phrase if the contract changes.
