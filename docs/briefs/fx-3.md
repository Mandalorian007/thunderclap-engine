## Goal

Particles a game author describes rather than programs: a sprite sheet per system with flipbook playback, per-particle spin, multi-stop size and colour curves, forces (attractors, vortex, turbulence) and depth collision in the kernel, sub-emission (a particle that dies spawns a burst, a particle that lives leaves a trail), emission from a mesh surface, and an `EffectDesc` JSON so an effect is an asset a tool or a human writes once and a game plays by name. The 2D harness stays pixel-identical.

STATUS row, *done when*:

- **Sprite sheets**: `ParticleSystemOptions.texture?: TextureLike` + `atlas?: { columns, rows }`; `EmitParams.tile?: number | [from, to]` (a fixed tile, or a flipbook that plays `from..to` over the particle's life; `tileRate?` plays at a fixed fps and loops); untextured systems keep today's quad. Alpha and additive both sample the texture (premultiplied for alpha). Test: the instance/particle struct gains the tile fields and an untextured system writes identical bytes to before.
- **Spin**: `EmitParams.rotation?: Range`, `spin?: Range` (rad/s), `alignToVelocity?: boolean` (today's stretch keeps working; spin applies to the quad about its centre). 2D and world space.
- **Curves**: `size`, `color` accept multi-stop curves (`sizeCurve?: number[]` 2..8 stops, `colorCurve?: RGBA[]` 2..8 stops, evaluated over life in the kernel from a small per-system curve table; `size`/`colorStart`/`colorEnd` stay as the 2-stop sugar). Test: stop evaluation at 0, 0.5, 1 against a CPU reference.
- **Forces**: `ParticleSystem.forces: ParticleForce[]` live array (`{ kind: 'attract', x, y, z, strength, radius }`, `{ kind: 'vortex', axis, x, y, z, strength, radius }`, `{ kind: 'turbulence', frequency, strength, seed }` (curl of value noise in the kernel), `{ kind: 'drag', amount }`), at most 8, uploaded with the system uniforms each frame; `floorY` stays. **Depth collision** `collide?: { bounce, friction }` for world-space systems with `readsDepth`: a particle whose projected depth passes the scene depth is pushed back along the view ray and bounces (the same-frame hook; off without it). Tests: attract pulls a parked particle toward the point in the CPU model used by the existing kernel tests; the WGSL compiles with and without forces (shader string snapshot).
- **Sub-emission**: `EmitParams.onDeath?: { params: EmitParams; count }` and `onLife?: { params; rate }` (a trail of particles): spawned on the GPU from the dying/living particle's position and a fraction of its velocity (`inherit?: number`), one level deep, budgeted by `maxSpawnsPerFrame`. Test: a burst with `onDeath` raises `alive` after the parents' life ends (countAlive path in the fake-GPU test if the harness has one; else e2e).
- **Mesh emission**: `EmitShape` gains `{ kind: 'mesh', positions: Float32Array, normals?: Float32Array, indices?: Uint32Array }` (area-weighted triangle sampling, velocity along the normal when `alongNormal`): built once into a sampling table on the CPU (`buildEmitSurface(geometry)` in `src/fx/emit-surface.ts`, geom's `Geometry` shape accepted directly) and uploaded. Test: sample distribution over two triangles of area 1 and 3 is ~1:3 over 4000 samples with a fixed seed.
- **Effect descriptors**: `src/fx/effect.ts`: `EffectDesc` (JSON-able: `{ systems: [{ name, options: ParticleSystemOptions minus textures by name, emitters: [{ params, rate, duration, delay, burst }] }], duration, loop }`), `createEffect(renderer, desc, { textures: Record<string, TextureLike> })` → `Effect` with `play(at: [x, y, z] | [x, y])`, `stop()`, `update(dt)`, `attach(getPosition)` (follows a socket or transform each update), `instances` (many plays share systems), `draw` through `frame.drawable` per system, `destroy()`; `validateEffectDesc(json)` with readable errors; `effect.json` loads through `src/assets` with no new loader kind (document the call). Three checked-in descriptors under `src/fx/effects/` (`hit-spark`, `smoke-puff`, `magic-aura` with a sub-emitter trail) used by the harness. Tests: validate rejects a bad stop count and an unknown texture; `play` twice runs two instances; `stop` ends emission but lets particles die.
- **Harness**: `harness/fx3.html` + `fx3.ts` + `fx3-state.ts`: `?sheet` (a flipbook sprite sheet system, state `tileSeen`), `?forces` (a vortex and an attractor, state `meanRadius` over time shrinking), `?collide` (particles raining on a slab with `readsDepth`, state `belowSlab` count must stay ~0), `?sub` (a firework: burst with `onDeath` burst, state `aliveAfterParents`), `?effect` (plays `magic-aura` on a moving point), `?still` parks everything. `e2e/fx3.spec.ts` (E-017: poll, no fixed waits), existing weather/particles specs green, `pnpm snap:check` 0 px.
- **Docs**: fx README *Particles* subsections (*Sprite sheets*, *Curves*, *Forces and collision*, *Sub-emission*, *Mesh emission*, *Effects*), types list; CHANGELOG block; ARCHITECTURE fx clause (one sentence); root README harness list + count line.
