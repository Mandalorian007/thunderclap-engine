## Goal

A game bakes its navmesh and static colliders at build time with one command and ships bytes, instead of baking at boot. The engine ships the bake as a Node script over the same pure modules the browser uses, a manifest that lists what was baked from what, and templates wire it in.

STATUS row, *done when*:

- **`scripts/bake.mjs`** (`pnpm bake <config>`): reads a `bake.config.json` (`{ "out": "public/baked", "nav": [{ "name", "sources": ["assets/level.glb" | "assets/level.json"], "options": NavBakeOptions }], "colliders": [{ "name", "sources", "options": ColliderBuildOptions }] }`), loads each glTF or geometry JSON through the existing glTF parser in `src/assets` (Node has no GPU: use the parse step only, never the upload; if the parser needs a `fetch`/`FileReader` shim, write the shim in the script, not in `src`), runs `bakeNavMesh` and the collider build, writes `<out>/<name>.navm` and `<out>/<name>.coll` plus `<out>/bake-manifest.json` (`{ version, bakedAt, entries: [{ name, kind, sources, sha256 of inputs, bytes, ms }] }`); `--check` exits 1 when any input hash differs from the manifest (CI), `--watch` rebakes on change, `--verbose` prints per-entry timing. Imports engine code through the built `dist/` or `tsx` the way `bench.mjs` does (copy its approach; state which).
- **Loading**: `src/nav` already has `importNavMesh`, `src/geom/collide` has `importCollider`. Add to `src/assets` one `loadBaked(url): Promise<ArrayBuffer>`-style helper only if the README shows nothing loads raw bytes today; otherwise document the existing call. A `bake-manifest.json` reader (`readBakeManifest(json)`) in `src/assets` is fine if it is 30 lines and typed.
- **Tests**: `scripts/bake.test.mjs` bakes a tiny checked-in geometry JSON (a floor and a box under `scripts/fixtures/`) into a temp dir, asserts the files exist, `importNavMesh` and `importCollider` accept them, the manifest hashes match, `--check` exits 0 then 1 after an input edit, and a second bake is byte-identical (determinism). Wire into `pnpm check` next to `create-game.test.mjs`.
- **Templates**: `templates/first-person` and `templates/third-person` get a `bake` script and a `bake.config.json` pointing at their level geometry; their boot loads the bytes when present and falls back to the runtime bake when the file is missing (so `pnpm dev` still works cold). `scripts/create-game` copies the config. Template checks green.
- **Geom notes**: `src/geom/README.md` gets a loud *in place* callout on `transformGeometry` (and any sibling that mutates), with the copy-first recipe; if `raycast` can take a register form additively (`raycastReg(bvh, ox, oy, oz, dx, dy, dz, …)` or similar) do it and switch `slide`'s lip check to it, else leave the wish in the report.
- **Docs**: root README *Baking* section (the command, config shape, CI `--check` recipe), `src/assets/README.md` loading paragraph, nav and collide READMEs point at the script, CHANGELOG block, ARCHITECTURE one sentence (Scripts/Tooling), count line.
- **Gate**: `pnpm check`, `pnpm snap:check` 0 px, full e2e once (templates specs green).
